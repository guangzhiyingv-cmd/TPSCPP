# 角色与战斗设计

[项目文档](README.md) / 角色与战斗

玩家靠近武器后装备，选择腰射、肩射或 ADS 开火。自己的镜头、后坐力和弹量反馈立即响应输入；服务器掌握弹药消耗、命中、生命值和淘汰结果。监听主机同时承担玩家与服务器两种角色。

## 从拾取到淘汰

远端玩家松开移动输入时，对手的 Iris 应随收到的加速度变化开始收步。角色移动复制携带服务器加速度，动画蓝图沿用现有急停判断。胶囊制动仍由角色移动组件负责。

| 玩家所在环节 | 玩法规则 | 继续查实现 |
| --- | --- | --- |
| 拾取、换枪 | 拾取提示只给可拾取的玩家。一次持有一把武器，装备新武器会掉落旧武器，其他玩家应看到同一把枪。 | [输入、网格挂点与装备复制](Combat/Character.md) |
| 移动、瞄准 | 鼠标右键共用。持枪腰射时按下即进入肩射，同帧开火使用肩射散布。0.20 秒前松开从当前镜头进度继续进入 ADS，按满后松开回到腰射。ADS 中短按退出。在 ADS 中长按也可转为肩射。瞄准结束冲刺，换弹期间禁止进入 ADS。镜头和瞄准镜只影响操作者视图。 | [瞄准输入和镜头过渡](Combat/Character.md) |
| 开火、换弹 | 武器表决定射击方式相关参数。服务器核算射击间隔与消耗；有限弹药换弹最多填入缺口和现有备弹中的较小值。开火或掉枪可中断换弹。 | [武器配置、开火与换弹](Combat/Weapons.md) |

## 按眼前的问题继续

Iris 真正落地时，操作者的第三人称镜头沿世界竖直方向短暂下沉，叠加衰减的小幅竖向震动，再回到跟随镜头。落地前的下降速度从 120 到 520 cm/s 对应从零到完整强度，满强度下沉约 5 cm，约 0.24 秒回稳。贴地走下矮台和开镜 ADS 时不触发。落地反馈由拥有者本地的 GameplayCue 播放，不叠加瞄准旋转或视野变化。

空手跑和冲刺在地面朝移动方向转身。每个移动步按胶囊与目标朝向之间的剩余偏航角选择转速，默认 45° 以内为 300°/s，45° 至 90° 线性提升，90° 及以上为 500°/s。该曲线只控制朝向，输入、水平速度、镜头和制动继续走原有路径。空中和跟随控制器朝向的持枪姿态使用原有转速。验收使用玩家镜头重放前跑点按 A/D 和左右 90° 急转，比较髋部摆幅与鞋底接地期间的水平位移。

地面折返按实际朝向方式统一分流。随移动转身时，空手跑及空手、持枪冲刺的近 180° 折返共用 Turnaround A/B；随镜头朝向时由 Pivot 处理方向切换。模拟代理接收服务器的朝向模式。按制动前水平速度与新加速度识别反向，按跑步或冲刺、实际转身侧及来步选片。入口读取前跑 Locomotion 组的 L/R 步相，在制动前的同一步附近按支撑脚的位置和速度选帧；输入立即生效。首次进入 Turnaround 时按步态设置姿势混合时间：普通跑沿用 0.099 秒，冲刺使用 0.24 秒线性混合，将直跑到低姿制动的重心转移分摊到更多帧。状态内再次折返沿用 A/B 自身的过渡。制动与蹬地保留片段的动作节奏。新方向上的跑出段可按实际速度与动画参考速度的比值限幅调速，由步幅扭曲补偿剩余速度差。调速与额外步幅按片段配置，退出使用片段时钟。角色移动组件控制位置与朝向，表现层抵消胶囊已经转过的角度。正常退出使用每条片段的固定退出时刻与前跑循环相位，同时匹配出步脚、骨盆高度和上身前倾及其变化速度。掉头姿势仍有混合权重时，片段时钟应继续推进；离地、失去移动意图或进入其他移动模式可中断。主图管理回转意图和状态权重，通过 ItemAnimLayers 接口请求全身回转。共享动画层以 A/B 两个独立的播放时钟处理连续反向，复用 Pivot 的朝向扭曲和步幅骨骼配置。原地片段以随片采样的行进速度与方向驱动扭曲，制动过零时衰减。共享物品层提供 Run 和 Sprint 的回转片段与接步参数；武器子层提供冲刺持姿，由共享层在正常 A/B 输出后经 UpperBodyMask 混入，换层快照单独输出。主机与客户端观察到的动作都从游戏移动状态驱动。

步枪动画层的站立肩射使用方向对应的 Rifle Walk Start 起步，再进入同方向的 Rifle Walk 循环。起步按实际位移推进，通过既有状态过渡进入循环。Iris 从角色主网格重定向，肩射移动速度为步行速度的一半（当前角色为 150 cm/s）。腰射与冲刺沿用 Jog，ADS 沿用 Walk，站立肩射和 ADS 折返按既有四向判定选择 Rifle Walk Pivot，腰射折返按方向选择 Jog Pivot，蹲伏优先选择蹲伏片段。停止独立选片。验收在同一水平地面比较短按和持续前进、后退及左右横移，记录脚尖高度、骨盆起伏与松键后的胶囊停止距离。

Iris 的第三人称动画将肩射与 ADS 视为同一瞄准姿势。站立待机共用瞄准选片，移动时共用上身持枪和 Aim Offset 混合，肩射沿用已有步枪步态。腰射与瞄准之间平顺过渡，肩射和 ADS 互切时持续保持瞄准姿势。验收在 GameLevel 双人 PIE 让监听主机和客户端轮流持步枪站立、横移并切换三态，由对端观察肩、肘和持枪手。

肩射步行跨下台沿时，胶囊按移动组件的查地结果贴地。若仍处于 Walking 且支撑面与胶囊同时突然降低，Iris、手中武器的画面和操作者的肩射镜头在短时间内逐渐跟到新高度。进入 Falling 后，镜头和角色完整跟随空中轨迹。枪口挂点与角色碰撞使用实际位置。[表现参数与关卡验收](Combat/ShoulderLedgeSmoothing.md)

Iris 的后脚仍搭在上层时，分别以鞋跟和前掌检查支撑。整只鞋通过屈膝让出穿入深度；只有少量鞋底压边时，可以顺着已迈出的方向脱离台面。足部修正沿用胶囊、骨盆与操作者镜头已有的运动。[支撑脚的实录与回归](Combat/IrisLedgeSupport.md)

当胶囊中心越过上沿、下方已查到可行走面时，肩射向外迈步的 Iris 可以提前降低身体，分摊原姿势即将出现的骨盆下降。步枪外观与躯干同步，双脚保留原先的世界空间接触目标。松键、反向或退出肩射时平顺地收回额外屈膝，起跳时可随上升伸腿。镜头继续由胶囊贴地平滑驱动。[重心转移、姿势中断与验收](Combat/IrisLedgeWeightTransfer.md)

肩射短落差的可选表现适用于从 Walking 踏入 Falling 且能很快接到下层的情形。Iris 伸出支撑腿，髋部承担超过腿部可达范围的高度差，双腕保持原持枪变换。接地后承重点随支撑物移动，鞋跟逐渐落下，再回到正常步态。胶囊、相机和实际枪口轨迹用于验收。当前保留手动对照开关。[短落差接地的设计与实测](Combat/IrisShortFallGrip.md)

是否使用这次短落差修正，由踏空时的瞄准状态决定。在空中松开肩射、切换 ADS 或在落地后松键时，已经开始的这一步继续承重和收脚。镜头与武器姿势仍立即响应输入。下一次踏空重新判断资格。

- 调整走动散布、连发后坐力或换弹时长，先找到武器蓝图实际使用的表行，再对照[参数及其生效位置](Combat/Weapons.md#按玩家看到的变化调参)。
- 主机正常、远程玩家异常时，先确定现象发生在拥有者、监听主机还是旁观者，再对照[三种网络角色的反馈](Combat/Damage.md#一枪在三种网络角色上的表现)。
- 要接着验证某个功能，从[战斗进度](CombatProgress.md)查看已有实现、历史故障和双端用例。
