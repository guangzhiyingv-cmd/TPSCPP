# 角色与战斗设计

[项目文档](README.md) / 角色与战斗

玩家靠近武器后装备，选择腰射、肩射或 ADS 开火。自己的镜头、后坐力和弹量反馈立即响应输入；服务器掌握弹药消耗、命中、生命值和淘汰结果。监听主机同时承担玩家与服务器两种角色。

## 从拾取到淘汰

| 玩家所在环节 | 玩法规则 | 继续查实现 |
| --- | --- | --- |
| 拾取、换枪 | 拾取提示只给可拾取的玩家。一次持有一把武器，装备新武器会掉落旧武器，其他玩家应看到同一把枪。 | [输入、网格挂点与装备复制](Combat/Character.md) |
| 移动、瞄准 | 肩射按住进入、松开退出；ADS 按下切换。瞄准结束冲刺，换弹期间禁止进入 ADS。镜头和瞄准镜只影响操作者视图。 | [瞄准状态与镜头过渡](Combat/Character.md#为什么-ads-分两段过渡) |
| 开火、换弹 | 武器表决定射击方式相关参数。服务器核算射击间隔与消耗；有限弹药换弹最多填入缺口和现有备弹中的较小值。开火或掉枪可中断换弹。 | [武器配置、开火与换弹](Combat/Weapons.md) |
| 命中、淘汰 | 即时射线和子弹可产生点伤害，火箭造成范围伤害。服务器结算生命；环境弹着与角色受击采用各自的特效。生命归零后交给 GameMode 计分和处理重生。 | [GAS、生命与特效](Combat/Damage.md) · [比赛规则](MultiplayerDesign.md) |

## 按眼前的问题继续

- 调整走动散布、连发后坐力或换弹时长，先找到武器蓝图实际使用的表行，再对照[参数及其生效位置](Combat/Weapons.md#按玩家看到的变化调参)。
- 主机正常、远程玩家异常时，先确定现象发生在拥有者、监听主机还是旁观者，再对照[三种网络角色的反馈](Combat/Damage.md#一枪在三种网络角色上的表现)。
- 要接着验证某个功能，从[战斗进度](CombatProgress.md)查看已有实现、历史故障和双端用例。
